^kit10^

A Google Sheets add-on for videogame localization teams.

^kit10^ turns a Google Sheets translation file into a dedicated CAT (computer-assisted translation) tool for videogame localization — without leaving Sheets. It runs as a sidebar and a floating panel next to your spreadsheet, and works directly on the Sheets tabs you already use to deliver translations.

What it does

  • Glossary and formatting tags: flags every glossary term and formatting tag (like <color=red> or line breaks) found in the source text, shows its approved translation, and lets you insert it with one click — so terminology and tags stay consistent across thousands of rows.
  • Translation memory: looks up similar or identical lines already translated elsewhere in the project and suggests reusing them, so the same sentence never gets translated twice from scratch.
  • Consistency checks ("Issue Snitch"): scans translated rows for missing/extra tags or terms, punctuation mismatches, spelling, and other localization-specific issues, with one-click fixes or dismissals.
  • Roles and permissions: a project can have an Admin and several Translators, each restricted to their own target language — enforced both inside the tool and, optionally, at the actual Google Sheets cell level.
  • Table Mode: a spreadsheet-like view of surrounding rows while translating, so you always see the context around the line you're working on.
  • Additional tools for auto-detecting untagged formatting codes, bulk-copying translations between sheets by row ID, comparing two deliveries of the same file, and tracking translated word counts and time spent.

Who it's for

Freelance and in-house videogame translators, and small localization teams, who already receive and deliver their translation work as Google Sheets files (a common workflow when working directly with game developers) and want glossary/consistency/translation-memory tooling without switching to a separate CAT application.

How your data is handled

^kit10^ only ever reads and writes the Google Sheets file it's installed on — see the Privacy Policy for the full details.
